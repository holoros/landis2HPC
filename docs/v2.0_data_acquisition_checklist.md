## The confirmed blocker

The PERSEUS calibration framework anchors against the FIA **multi-cycle hindcast**: each plot's aboveground biomass observed at FIRST_INVYR and at each remeasurement cycle (typically every 5–7 years). Building `untreated_plots_{ST}.csv` requires per-plot, per-cycle biomass, which comes from the FIA **TREE** table summed over live trees with the `DRYBIO_AG` field.

Diagnostic run of `tools/build_plot_list.py` on the MN data currently on Cardinal:

```
Reconstructed 62255 plot keys from COND
COND status for 54850 plt_cn
TREE rows used: 20096; biomass for 557 plt_cn (Jenkins fallback)
Plots passing filters: 0
```

The MN COND table is complete (62,255 plot keys, cycles 1977–2024). But the MN_TREE.csv currently on Cardinal is the **initial-communities tree-map snapshot** — 557 plots, keyed by TM_ID, with no overlap with the multi-cycle COND plt_cn values and no DRYBIO_AG field. It was built to generate the IC raster, not for hindcast pairing.

Result: zero multi-cycle plots can be assembled from the data on hand. The full FIA TREE table is the missing piece.

## What to download (per state)

From the FIA Datamart at <https://apps.fs.usda.gov/fia/datamart/datamart.html> (CSV by state):

| Table | Why needed | Key fields |
|---|---|---|
| `{ST}_PLOT.csv` | Plot key → cycle grouping, lat/lon | CN, PREV_PLT_CN, STATECD, UNITCD, COUNTYCD, PLOT, INVYR, LAT, LON |
| `{ST}_COND.csv` | Forested + untreated filtering (already on Cardinal for MN) | PLT_CN, COND_STATUS_CD, TRTCD1/2/3, OWNCD |
| `{ST}_TREE.csv` | **Per-cycle aboveground biomass** (the missing piece) | PLT_CN, STATUSCD, SPCD, DRYBIO_AG, TPA_UNADJ |

For MN, only the **TREE** table (full multi-cycle, with DRYBIO_AG) and the **PLOT** table are missing — COND is already present. For IN and OH, all three tables should be downloaded fresh (their COND tables are not on Cardinal either).

State codes: Minnesota = 27, Indiana = 18, Ohio = 39.
