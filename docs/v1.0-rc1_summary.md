# PERSEUS v1.0-rc1 one-page summary

**Tag:** github.com/holoros/landis2HPC/releases/tag/v1.0-rc1 (commit c2f9fb6, 2026-05-17)
**Author/maintainer:** Aaron Weiskittel (aaron.weiskittel@maine.edu)
**Co-authors:** Melissa Lucash, Rob Scheller

## What this release contains

**Full PERSEUS framework** — multi-state LANDIS-II Biomass Succession calibration against the FIA multi-cycle hindcast, demonstrated across Maine, Georgia, and Washington forests.

**Three-state best-fit calibrations** at multiple tiers of the calibration ladder:

| State | Tier 2 | Tier 1.5 | Tier 1 | Tier 0 (literature) |
|---|---|---|---|---|
| Maine | finalized (26 params) | n/a | n/a | reference |
| Georgia | rc1 snapshot (54 params, LL=+15.75 converged across 3 iters) | n/a | θ=0.30 finalized | reference |
| Washington | rc1 snapshot (50 params, LL=−50.0 from iter1) | per-ecoregion finalized | θ=0.30 finalized (active-growth) | reference |

**Six validated disturbance extension agents** for LANDIS-II v8 Apptainer with the .NET 8 console DLL patches:
- Original Wind v4 (all states)
- Original Fire v5 (all states)
- Climate BDA: spruce budworm (ME), southern pine beetle (GA), mountain pine beetle (WA)
- Hurricane v3 (GA, with NOAA HURDAT2-derived climatology)

**Six-test validation framework** — k-fold CV, time-out-of-sample, leave-one-ecoregion-out, cross-state, bootstrap CI, IC perturbation.

**Paper-novel methodological contribution: calibration degeneracy diagnostic.** At very low θ, LANDIS-II produces near-zero growth across the projection horizon; the likelihood minimum becomes a trivial fit. Two guards in the patched CMA-ES driver: active-growth fraction check + empty-aggregator detection.

**Carbon Atlas v1 dashboard** — single-file HTML, browser-only, no server. Reads each state's calibrated trajectory data and renders interactive comparisons.

## Cross-state finding worth previewing

Tier 2 multiplier panels show a striking directional asymmetry:

- Maine multipliers cluster around 1.0–2.3 (red): literature defaults systematically underestimated regional growth
- Georgia + Washington multipliers cluster around 0.1–0.9 (blue): literature defaults systematically overestimated regional growth

This is the headline empirical finding for the methods paper: literature parameters are biased in opposite directions across the eastern temperate vs. southeastern pine vs. western montane ecoregions. Calibration changes 100-yr per-cell biomass asymptotes by 7%, 35%, and 67% respectively.
